# BabyPete
### An animated workspace for supervised AI development

[← Back to Peter's portfolio](https://github.com/Ginnnyyyy)

**Context:** Personal project in development · **Stack:** Python, SQLite, Google ADK

## The idea
Make AI-assisted project work easier to inspect: who has a task, what happened, what came back and what needs an owner's decision.

## The current implementation
A local animated office displays role definitions, recorded tasks and events. A command-line runtime persists those records in SQLite. Assignment packets and returned reviews support a supervised workflow.

## What the project demonstrates
- Modelling tasks, events and role responsibilities.
- Building an interface around recorded workflow state.
- Designing cancellation, recovery and explicit owner decisions.
- Keeping implemented behaviour separate from future automation goals.

## Status and limits
This is a local, supervised prototype. Automatic worker dispatch, autonomous software delivery and production hosting are future work. An animated desk represents recorded state; it does not prove an autonomous agent is running.

Source and internal operational records remain private.
