# Weather Data Analysis
### Completed coursework · ICT283 Data Structures and Abstraction

A C++ console application for exploring timestamped weather measurements. Built across two assignments, progressing from a custom dynamic vector to a map abstraction and AVL traversal.

## What I built
- CSV loading with column-name lookup.
- Wind/temperature means and sample standard deviations.
- Monthly solar totals and exported summaries.
- Date/time filtering and Pearson correlation in the second version.
- Separate model, controller, view and statistics classes.

## Progression

| Assignment 1 | Assignment 2 |
| --- | --- |
| Custom dynamic vector | Encapsulated STL vector and map |
| Month/year summaries | Adds date/time keys and multi-file loading |
| Mean and sample standard deviation | Adds mean absolute deviation and correlation |
| Console menu and export | AVL traversal supports the correlation workflow |

## Verification
Both versions compile. Twelve supplied test executables and two synthetic-data menu/export smoke checks run successfully after a filename-case fix and a stale map-test API correction. The demo is based on six invented readings; these checks are not exhaustive correctness or scientific validation.

This is completed university coursework, with known parsing/export limitations documented in its source repository. The public page is a project summary; source and original submission artifacts are managed separately.
